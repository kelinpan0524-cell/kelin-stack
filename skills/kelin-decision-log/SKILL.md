# 决策日志

只记**会改变后续行为**的决定。日常小选择不记。

## 什么时候记

- 在两个方案里选了一个，另一个被放弃；
- 接受了某个已知风险；
- 改了方向（本来要做 A，改成 B）；
- 定了对外承诺（接口、时间、价格）。

## 字段

```sh
node skills/kelin-decision-log/scripts/log.mjs decisions.tsv \
  阶段 决策 为什么 证据 结果
```

- 阶段：设计 / 实现 / 验证 / 发布 / 复盘；
- 决策：一句话，动词开头；
- 为什么：被放弃的方案是什么，为什么不选；
- 证据：命令输出、链接、数据；
- 结果：待验证 / 有效 / 有害。

## 为什么用 TSV

能直接拖进表格筛选，也能被脚本读。脚本会处理制表符、换行和以 `=`、`+`、`-`、`@` 开头的单元格，避免在表格软件里被当成公式执行。

## 反模式

- 事后补记，理由已经想不起来；
- 只记结果不记放弃的方案；
- 把所有小事都记进来，日志失去信号。
