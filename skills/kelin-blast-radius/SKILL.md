# 影响面

改之前先回答“如果这里错了，会炸到哪”。答案要带证据，不能靠印象。

## 五个面

1. **调用方**：谁调用这个函数/接口/表。用搜索和引用找，不靠记忆；
2. **数据**：谁读这份数据、有没有下游导出、能不能重建；
3. **测试**：哪些测试会覆盖到，哪些没有覆盖；
4. **外部**：有没有第三方系统、定时任务、报表依赖；
5. **回滚**：出问题能不能撤回，撤回要多久，会不会丢数据。

## 输出

```markdown
| 面 | 受影响的东西 | 证据 | 怎么验证 |
| --- | --- | --- | --- |
| 调用方 | 报价导出、批量报价 | `grep -rn "calcQuote" src/` 12 处 | 跑 quote 测试 |
| 数据 | quote_lines 表 | 只读，不写 | 对比导出前后行数 |
| 外部 | 每日报表 | cron 07:00 读该表 | 次日看报表 |
| 回滚 | 迁移脚本不可逆 | 新列可空，旧代码兼容 | 灰度先关开关 |
```

## 分级

- **高**：影响钱、客户数据、对外接口、不可逆迁移 → 必须分批 + 灰度 + 回滚演练；
- **中**：内部流程、可重跑 → 常规验证；
- **低**：纯展示、可随时回退 → 快速验证。

## 反模式

- 只 grep 一次就宣布“没有影响”；
- 不考虑定时任务和历史数据；
- 不问“回滚要多久”，等到出事才想。
